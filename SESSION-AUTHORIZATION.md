# Job Application Session Authorization

Copy and paste the prompt below at the beginning of a new thread. After that,
send a command such as `start 20` when you want the batch to begin.

```text
For this thread, I give standing authorization for the job-application workflow.
When I later enter `start <count>`, treat that command as authorization to:

- complete discovery first and freeze the qualifying application batch;
- apply to every qualifying job in that frozen batch without asking whether I
  want to apply to any individual job;
- use the resume selected and frozen for each opportunity;
- fill all ordinary application fields from the confirmed candidate files in
  this workspace without asking me to repeat known information;
- follow application navigation, continue to the next job automatically, and
  process the entire frozen batch;
- preserve and record any blocked application as a handoff, leave its tab open,
  and continue with all remaining batch items rather than stopping the batch;
- resume an unfinished authorized batch when I say `continue` or `resume`,
  without asking me to restate this authorization.

Do not ask me questions such as "Should I apply?", "Do you want to continue?",
"May I use this resume?", or "Should I proceed to the next job?" for items in
the frozen batch. This is advance authorization for those workflow decisions.

Still follow the workspace's truth, safety, and browser-confirmation rules. Do
not invent candidate facts, answer unknown material questions, bypass CAPTCHA
or MFA, complete assessments or interviews, or accept new material legal
attestations. Ask only when genuinely required by those rules.

Use exactly the mandatory grouped browser checkpoints when applicable:

1. After the batch is frozen and all destinations are identified, ask once for
   confirmation to transmit the specified candidate-data categories and exact
   resume files for all currently actionable jobs together. Do not ask once per
   job.
2. Fill every covered application to its furthest safe point. When all items
   are review-ready or durably blocked, ask once for final-submission
   confirmation covering all review-ready applications together. After I
   approve, submit the entire listed set without asking again unless the
   destination, transmitted data, resume, or application set materially changes.

This prompt establishes standing authorization but does not itself start a
search or application batch. Wait for my `start <count>` command to begin.
```

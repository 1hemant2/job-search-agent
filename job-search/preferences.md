# Job Search Preferences

## Priority Roles

1. Node.js Backend Engineer
2. Backend Engineer
3. Software Engineer I / SDE 1
4. Software Engineer II / SDE 2 when the experience bar is realistic
5. API Engineer
6. Backend-heavy Full Stack Engineer
7. Platform Engineer
8. Distributed Systems Engineer
9. Java / Spring Boot backend roles where 2 years of hands-on independent project experience and transferable professional backend skills are acceptable

## Strongest Current Categories

- Node.js backend services
- PostgreSQL-heavy backend and analytics systems
- Asynchronous processing, queues, workers, and event-driven systems
- Redis caching and messaging
- Backend infrastructure using Docker, Kubernetes, CI/CD, and GitOps
- Multi-tenant systems and usage analytics

## Deprioritize or Avoid

- Frontend-only roles
- UI/UX roles
- Mobile roles
- QA or manual testing
- Support engineering
- WordPress
- Low-code or no-code roles
- Clearly senior, staff, or principal roles requiring substantially more experience

## Search and Decision Defaults

- Prefer backend-heavy work regardless of title.
- Apply automatically at scores of 70 or higher when there is no hard blocker.
- Save scores of 60-69 for review.
- Skip scores below 60.
- A small experience gap is acceptable when the technical match is strong.
- Java screening answers must distinguish 2 years of hands-on independent project experience from 0 years of professional production Java experience.

- Preferred India locations: Bengaluru, Pune, Noida, Delhi, Delhi NCR, Gurugram, Hyderabad

- Remote, hybrid, or onsite preference: All are acceptable
- Willingness to relocate: Yes, for suitable opportunities
- Company-size preference: Any, including approximately 10 to 10,000+ employees
- Industry exclusions: None
- Notice period: Officially 60 days, negotiable to 30 days
- Travel willingness: Yes, up to 25%

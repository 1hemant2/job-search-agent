# Compensation

- Current compensation: INR 6.93 LPA
- Minimum acceptable compensation: 13 LPA
- Target compensation: 13 - 16 LPA
- If one annual India number is required: INR 14 LPA
- Expected monthly in-hand salary: INR 85,000
- Preferred currencies: INR, EUR, USD, GBP
- Willingness to disclose current compensation: Yes

## Application Rules

- For an India annual range, use INR 13-16 LPA.
- If an India form accepts only one annual figure, use INR 14 LPA.
- If compensation is optional or free text, use "Negotiable" when appropriate.
- If a form asks for expected monthly in-hand or take-home salary, use INR 85,000.
- Do not describe INR 85,000 as monthly gross salary or as the direct monthly equivalent of INR 14 LPA.
- For positions outside India, use "Negotiable" when permitted. If a numeric value is mandatory, request a country- and currency-specific answer.
- For an international role requiring a number, research the current market range and the company's reported compensation for that role, then select a realistic figure aligned with the candidate's skills and experience. Record the source and value used in application history.
